# Customer Churn Analysis Project

An end-to-end Customer Churn Analysis project built using SQL Server, Power BI, and Machine Learning. This project focuses on analyzing customer behavior, identifying churn patterns, and building predictive models to help businesses reduce customer attrition and improve retention strategies. :contentReference[oaicite:0]{index=0}

---

## Project Overview

This project aims to analyze customer churn data and generate actionable business insights through data analysis, dashboard visualization, and machine learning prediction models.

The project workflow includes:

- Data Extraction & Cleaning using SQL Server
- Data Transformation using Power BI
- Interactive Dashboard Development
- Machine Learning Model Building using Python
- Customer Churn Prediction Analysis

The project helps businesses understand:
- Why customers leave
- Which customers are likely to churn
- Key factors affecting retention
- Revenue impact of churn

---

## Objectives

- Analyze customer churn trends
- Identify high-risk customers
- Build interactive business dashboards
- Create churn prediction models
- Help businesses improve customer retention strategies

## Project Workflow

### 1. Data Cleaning & ETL (SQL Server)
- Imported raw customer dataset into SQL Server
- Performed ETL operations
- Removed null values and duplicates
- Standardized column formats
- Prepared clean analytical dataset

### 2. Data Transformation (Power BI)
- Data modeling
- DAX measures creation
- KPI calculations
- Relationship building
- Data formatting

### 3. Dashboard Development
Built interactive dashboards to visualize:
- Customer churn rate
- Total customers
- Active customers
- Churned customers
- Revenue impact
- Customer demographics
- Subscription behavior

### 4. Machine Learning Model
- Built a Random Forest Classification model
- Predicted potential churn customers
- Evaluated model accuracy
- Exported prediction results into Power BI

## Key Insights

- Customers with month-to-month contracts show higher churn rates
- Electronic payment users have higher churn probability
- Long-term contract customers are more loyal
- Customers with multiple services tend to stay longer
- Churn significantly impacts recurring revenue
